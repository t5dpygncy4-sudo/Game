# SALAMANDER-X · 沙罗曼蛇 X

横向卷轴射击游戏，单 HTML 文件实现。基于 HTML5 Canvas 2D 渲染。

游戏入口：`game.html`

## 操作

- 方向键 / WASD：移动
- 空格 / J：射击
- 数字键 1-6：消耗能量晶体升级对应能力
- P / Esc：暂停
- 回车：开始 / 重开

## 更新日志

### 本次会话更新

#### 1. 多级升级系统修复（加速/追踪弹）
- **问题**：加速升级只能加一次。
- **根因**：`speedLevel` / `missileLevel` 多级系统被重置回旧的 `abilities.has()` 单级判断；同时 HUD 用 `abilities.has('speed')` 判定"已学"，导致买了之后 HUD 无变化，看起来像只能加一次。
- **修复**：
  - 重新接入 `speedLevel`（0-3，每级 +60 速度 / +400 加速度）与 `missileLevel`（0-3，每级 +2 枚导弹 / +40 速度）。
  - HUD 改为按等级判定，显示 `加速 1/3`、`加速 2/3`、`加速 3/3`，满级显示`满级`。

#### 2. CFG 补全（关键崩溃修复）
- **问题**：`fireMissiles()` 引用 `CFG.missileSpeed`，但 CFG 中未定义，导弹开火即崩。
- **修复**：
  - 新增 `missileSpeed: 300`
  - 新增 `maxCrystals: 10`（能量晶体上限）
  - `fireCooldown: 0.13 → 0.156`、`laserCooldown: 0.16 → 0.192`（降低 20% 射速）

#### 3. 能量晶体上限
- 持有上限 10，满后碰到晶体直接消失不再累加。
- HUD 显示 `能量: x/10`。
- 晶体漂移速度 `vx -70 → -40`，更易拾取。

#### 4. 生命补给掉落道具（新功能）
- 新增 `LifeDrop` 类：粉色心形，脉冲发光，向左漂移。
- **Boss 击败必定掉落**一个生命补给。
- **大型敌人**（大陨石 / 守卫者）击败有 **15% 概率**掉落。
- 拾取生命 +1，上限 5（满后提示"生命已满"）。

#### 5. 过关过渡动画修复
- **问题**：过关后飞机停在击败 Boss 的最右端，没有从左侧飞入。
- **根因**：击败 Boss 后直接 `startLevel(idx+1)` + `state='PLAYING'`，未重置玩家位置。
- **修复**：新增两个过渡状态：
  - `LEVEL_OUT`：飞机向右加速飞出屏幕。
  - 飞出后 `startLevel` 并把飞机放到屏幕左侧外（`camX-60`），给 1.5 秒无敌。
  - `LEVEL_IN`：飞机从左侧匀速飞入，接近目标位置减速，到达 `camX+160` 后恢复 `PLAYING`。
  - 过渡期间玩家跳过输入响应与位置限位，由 `Game.update` 直接控制位移。

#### 6. 炸弹功能移除
- 移除 `bombs` 属性、`useBomb` 方法、Shift/K 绑定、HUD BOMB 显示、标题屏炸弹说明。

## 技术要点

- 世界坐标（`player.x`, `camX`）与屏幕坐标（`sx = x - camX`）分离。
- 游戏状态机：`TITLE / PLAYING / BOSS / PAUSED / GAME_OVER / WIN / LEVEL_OUT / LEVEL_IN`。
- Boss 触发：`scrollDistance >= level.length`；Boss 出现后清空障碍物腾出战斗空间。
- Boss 阶段：按 HP 比例（>50% 阶段1，>25% 阶段2，否则阶段3）。
- 障碍物系统：`hitBoxes()` 返回多区域碰撞矩形。
- 视差星空：主题系统（asteroid / fortress / core / space）。
- Node VM 沙箱可用于无浏览器运行时测试（需 stub canvas / audio / window / performance）。

## 已知历史问题

- `game.html` 曾多次在会话间被重置为旧版本，导致 Level 4、过渡动画、多级升级等改动丢失。若发现功能回退，请对照"更新日志"核查代码是否仍在最新状态。
