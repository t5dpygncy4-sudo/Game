# 中国象棋 · 本地运行说明

## 一、环境准备

1. 安装 **Node.js**（必需，版本 18 或以上）
   - 下载地址：https://nodejs.org
   - 选择 LTS（长期支持版），下载后一路下一步安装即可
   - 安装完成后，打开命令行（Win+R 输入 cmd）执行 `node -v` 能看到版本号即成功

## 二、解压项目

1. 把 `chinese-chess.zip` 解压到一个文件夹，例如 `D:\chinese-chess`
2. 解压后文件夹内应能看到 `package.json`、`src` 文件夹、`index.html` 等

## 三、安装依赖并启动

1. 打开命令行（Windows 按 `Win+R`，输入 `cmd` 回车）

2. 进入项目目录（根据你的实际解压路径修改）：
   ```cmd
   cd /d D:\chinese-chess
   ```

3. 安装依赖（首次运行需要，约 1 分钟）：
   ```cmd
   npm install
   ```

4. 启动开发服务器：
   ```cmd
   npm run dev
   ```

5. 看到如下输出即启动成功：
   ```
     VITE v6.x.x  ready in xxx ms
     ➜  Local:   http://localhost:5173/
   ```

## 四、打开游戏

用浏览器（Edge / Chrome 等）打开：

**http://localhost:5173/**

即可开始对弈。

## 五、功能说明

- **双人对弈**：默认模式，红方先行，两人轮流操作
- **人机对战**：点击左侧"人机对战"，AI 执黑，可选三档难度
  - 初级：会偶有失误
  - 高级：稳健
  - 大师：凌厉，搜索更深
- **操作**：新局 / 悔棋 / 翻转棋盘 / 规则速查 / 静音开关
- **声效**：走子、吃子、将军、胜负均有音效（首次点击棋子后激活）

## 六、其他命令

| 命令 | 作用 |
|------|------|
| `npm run dev` | 启动开发服务器（日常使用） |
| `npm run build` | 打包生产版本到 dist 文件夹 |
| `npm run preview` | 预览生产构建 |
| `npm test` | 运行规则引擎单元测试 |
| `npm run lint` | 代码检查 |

## 七、常见问题

**Q: `npm install` 很慢怎么办？**
A: 可使用国内镜像加速：
```cmd
npm config set registry https://registry.npmmirror.com
```
然后再执行 `npm install`。

**Q: 端口 5173 被占用？**
A: Vite 会自动换用下一个可用端口（如 5174），看终端输出提示即可。

**Q: 想打包成静态网页部署？**
A: 执行 `npm run build`，生成的 `dist` 文件夹可直接放到任意静态服务器或对象存储上。
